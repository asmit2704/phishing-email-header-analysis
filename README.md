\# Phishing Email Header Analysis



\## Project Overview



This project demonstrates how a SOC analyst investigates suspicious emails through email header analysis and threat intelligence validation.



\## Objectives



\* Extract email headers

\* Identify sender IP addresses

\* Validate SPF, DKIM, and DMARC

\* Investigate sender reputation

\* Analyze URLs

\* Document findings



\## Tools Used



\* Gmail

\* AbuseIPDB

\* VirusTotal



\## Skills Learned



\* Email Security

\* Phishing Investigation

\* Threat Intelligence

\* IOC Validation

\* Security Reporting
